HOW TO USE
================================================================================

OPTION 1: Automatic (Global Environment)
----------------------------------------
The ~/.local/bin/env file is already sourced by your shell profile.
You already have these aliases available:
  - omega           -> cd to OmegaKG root
  - omega-scripts   -> cd to scripts directory
  - omega-vault     -> cd to Obsidian vault
  - omega-logs      -> cd to logs directory
  - omega-start     -> Start full stack
  - omega-cleanup   -> Stop all services
  - omega-test      -> Run test script

OPTION 2: Manual (Project Environment)
---------------------------------------
For project-specific features, source the environment:

  cd /d/projects/OmegaKG/Omega_KG_stable
  source ./source_env.sh

This adds additional aliases:
  - omega-cd        -> Go to project root
  - omega-health    -> Check server health
  - omega-shell     -> Activate Poetry shell
  - omega-verify    -> Verify stack setup
  - omega-install   -> Install dependencies
  - omega-run       -> Run capture server
